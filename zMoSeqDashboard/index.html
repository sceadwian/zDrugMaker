Help & instructions

1. Choose your data

Recommended: run launch.py with Python, or double-click Start Dashboard.bat on Windows. This uses only Python's standard library, opens your browser and lists current files in data_MoSeq_raw. “Refresh local data folder” rescans the folder and reloads the selected source. Keep the launcher open while using this mode; Ctrl+C stops it.

No launcher: open index.html directly. The included four-study catalog is a snapshot of the supplied raw files (refreshed whenever the launcher starts). To read new or edited files, choose Choose data folder and select data_MoSeq_raw, or use Open a data file. Browsers require this explicit selection; a local page cannot silently scan nearby folders. Folder selection lists TXT, TSV and CSV files. Select one in the Active dataset menu.

Files you open are read in memory, not sent to an external server or copied into a folder. The optional Python server accepts connections only on this computer. Keep your source files in data_MoSeq_raw yourself. File selection is the fallback if your browser does not offer directory selection.

2. Select syllables and compare treatments

The initial view shows six syllables with the highest overall mean usage among available observations. Use the searchable checkboxes to add or remove plots. Top 6 and Top 20 replace the selection with the highest overall mean-usage syllables. “Select matches” adds the filtered syllables; “Clear all” clears the entire selection. Group order follows the source group IDs (numeric when possible). All groups are displayed, even when a study has more than three.

Use a shared y-axis for direct visual comparisons between selected plots. Independent axes show small values more clearly but can exaggerate visual similarities. Resize the grid and optionally hide animal dots. The chart title and export always identify the dataset.

3. Mean and standard error

Mean is the arithmetic average of the available animal values for a treatment and syllable. SEM = sample standard deviation / √n, using sample variance with denominator n − 1. Error bars show mean ± SEM; the axis can extend below zero to preserve the full lower error bar. With one observation the mean is shown, but SEM is unavailable. With no observations there is no bar. Each chart lists the actual n per treatment.

Zero usage is a valid observation. Blank values, NA, N/A, NaN and null are treated as missing and reported. Missing rows are not filled with zeros. Duplicate animal–syllable rows, conflicting animal assignments, inconsistent group labels and invalid values prevent loading the file. Usage values must be fractions from 0 to 1; use the percentage display option to multiply values and SEM by 100.

4. Export to Prism

Choose Prism table on a plot, then copy its table into a Prism Column data table for unpaired groups, or download a tab-separated file. Each treatment occupies a separate column, with independent animal observations down that column. Unequal group sizes leave blank padding. For missing values, the subject's position within its group is left blank. The optional ID export preserves the exact animal-to-value mapping.

The selected-summary export contains syllable, group, treatment, n, mean, sample SD and SEM. It is a summary, not a substitute for individual-animal data when doing statistics. SVG downloads save vector figures. Exports use the currently selected units. Prefixes are added to dangerous spreadsheet text labels to prevent formula interpretation.

5. Add labels and commentary

Open Notes & labels, or choose Note on a plot. Select a syllable, animal or treatment group by its original ID, then enter a display label and comment. Edits stay in the current page session as you type; Apply note refreshes the displayed list. Notes do not change values, rename source IDs or exclude animals from calculations.

Save notes file downloads a separate file such as MOS-VIZ1_usage_bysubject_LSD.moseq-notes.json. Move it beside the matching raw file to share them together. On your next visit, load the raw dataset and choose Open notes file; notes are not loaded automatically. The filename and content fingerprint must match. An asterisk marks changes not yet downloaded. Notes for other datasets stay in memory while you switch files; return to each dataset to save its notes before closing the page.

Custom treatment labels appear on graph axes, in the legend and in each plot's mean ± SEM table. Custom syllable labels become the bold plot heading; the original syllable ID appears below in smaller green text. Saved SVG figures use your labels too. Prism and data exports retain original treatment names. Value tables beneath plots show the selected units and five significant digits; exports retain full precision. An unavailable SEM appears as N/A.

6. Combined syllables

Choose two or more syllables in the sidebar, open the Combined syllables workspace, enter a name and select Add selected syllables. Create multiple combinations to compare their graphs. Each animal's values are added first, then the treatment mean and SEM are calculated from those totals. If any component is missing, the animal's total is missing. Overlapping combinations are not independent outcomes. Prism tables contain the individual summed values. Save your session to retain the definitions.

7. Heatmaps

Use the sidebar to select syllable columns. Heatmaps show treatment means or individual animals as rows; choose a palette and low, midpoint and high thresholds in the displayed units. Thresholds must be strictly increasing. Colors saturate outside the selected range; gray means missing. Fit color range uses zero to the maximum selected value. Hover over cells for details. Adjust cell width and height with the sliders, or choose Square cells. Dimensions and palettes are saved with the session and used in SVG exports. Viridis, Magma, Cividis, Mako and Turbo are available alongside five custom two-color gradients and the existing palettes. Cell width can go down to 8 px. Choose Horizontal (normal) or Rotated syllable labels; narrow columns use compact IDs. Heatmaps initially select all syllables with individual-animal rows, original fractions, 12 × 12 px cells and Turbo. Older sessions adopt this preset once, preserving notes and descriptions; sessions saved after this update retain your subsequent choices. Restore heatmap defaults returns to this preset. The Test description box is directly below the Usage heatmap heading. Heatmap units are separate from bar-chart units. Use Test description for test article, doses, dose volume and vehicle details; its checkbox shows or hides that text on the heatmap and in SVG exports. Text and visibility are saved with the session. Individual animals are separated by labeled treatment headers and gaps. Export the SVG or its values, with syllables in columns. This view shows actual usage without clustering or row normalization, so it may differ from transformed upstream heatmaps.

8. Save your work

With the Python launcher and an active dataset from its live folder, Save session writes directly beside the raw file in data_MoSeq_raw, using the existing _session.json filename. The previous saved version is kept as _session.previous.json. On a new visit, choosing that dataset restores its matching session automatically. A changed raw file prevents restoration of an older session. Restart the launcher after an application update.

A session contains original dataset text, notes, selections, combined syllable definitions, workspace and heatmap/display settings. Save explicitly before closing. Open session can restore a snapshot manually. In direct HTML mode or for files outside the live raw folder, Save session still downloads a file. Separate notes-only files also still use downloads. Raw measurements are never overwritten.

9. Close the dashboard

Choose Close dashboard at the bottom of the sidebar. The dialog lists unsaved notes and session settings across datasets visited in this tab. Save the current session, keep working to save another dataset, or close without saving. Closing stops the Python launcher; the browser shows a closed screen and you can close the tab normally. Save work in any other tabs using this launcher first. In direct HTML mode there is no server to stop. Restart the launcher once after this update to enable the close action.

Input format and scope

Required columns: subject, group, syllable, usage, treat. Tab-separated or comma-separated text is accepted, including quoted fields. One animal must belong to one group, with at most one row per syllable. The first version displays one file at a time. Syllable numbers from different files or models must not be assumed to represent the same behavior. This app does not name behaviors or run hypothesis tests.

This dashboard supports the exploration of mouse behavioral data from studies of four psychedelic compounds, including two hallucinogenic and two non-hallucinogenic compounds. It brings treatment comparisons, per-animal syllable combinations, editable heatmaps and annotations into one interface, with individual-value exports for statistical analysis in GraphPad Prism.

Operational development

John Huxter, Sandy Thevarkunnel and Matt Brown are developing the operational side of Transpharmation's MoSeq capabilities.

What is MoSeq?

Motion Sequencing (MoSeq) was developed by the Datta laboratory in the Department of Neurobiology at Harvard Medical School, with foundational work by Alex Wiltschko and colleagues. It combines three-dimensional video of mice with unsupervised machine learning to identify recurring, brief movement patterns called behavioral “syllables,” and the sequences in which they occur. The aim is to describe the structure of behavior from the data and reveal how it changes with experimental conditions, rather than relying only on predefined human scoring categories. Datta Lab: Understanding Action · MoSeq methods and protocol.

This explorer works with usage tables produced by MoSeq. It does not fit MoSeq models, infer syllables from video, or run hypothesis tests. Syllable IDs from separately fitted models need not describe the same behavior.

Local by design

Built with HTML, CSS and plain JavaScript, with an optional standard-library Python launcher. No library installation, account or network connection is required to use the dashboard. Data and notes stay on your computer. External reference and contact links open only when you choose them.

Viridis and Magma color tables are credited to Nathaniel J. Smith, Stefan van der Walt, and Eric Firing (Viridis), released under CC0. Color-map source. Cividis and Turbo tables come from Matplotlib; Mako comes from Seaborn. Source and license notices are included in PALETTE_LICENSES.md.
